# Modular Enemy AI (Unity)

Модульная система искусственного интеллекта врагов для Unity. Проект находится в разработке (WIP) и создается с упором на чистую архитектуру (SOLID) и оптимизацию производительности. 

## Особенности архитектуры

* **Object Pooling:** Использование `Queue<EnemyBrain>` для спавна и деспавна врагов. Полностью исключает аллокацию памяти в процессе игры и снижает нагрузку на Garbage Collector.
* **State Machine:** Логика поведения управляется центральным компонентом `EnemyBrain` (состояния Idle, Chase, Attack).
* **Разделение ответственности (SRP):** Здоровье (`EnemyHealth`), навигация (`EnemyMoving`), атака (`EnemyAttack`) и зрение (`EnemyVision`) вынесены в изолированные скрипты.
* **Троттлинг вычислений:** Тяжелые операции, такие как `NavMeshAgent.SetDestination` и физические рейкасты, ограничены по времени (Time-based интервалы) и не вызываются в каждом кадре `Update()`.
* **Событийно-ориентированная модель:** Компоненты взаимодействуют через C# события (`Action`), что обеспечивает слабую связность систем.
* **Dependency Inversion:** Система нанесения урона работает исключительно через интерфейс `IDamagable`.

## Структура инициализации

Используется каскадная инициализация данных сверху вниз:
1. `EnemySpawner` берет данные из `ScriptableObject` и передает их в `EnemyBrain`.
2. `EnemyBrain` распределяет специфичные параметры по подкомпонентам (скорость передается в навигацию, урон и кулдаун — в скрипт атаки).
3. При падении здоровья до нуля, `EnemyHealth` вызывает событие, которое перехватывается спавнером для возврата объекта в пул.

## Требования
* Unity 2022.3 или выше.
* Настроенный NavMesh на сцене.

## Использование
1. Добавьте компоненты на префаб врага.
2. Реализуйте интерфейс `IDamagable` на объекте игрока.
3. Назначьте префаб и точки спавна в `EnemySpawner`.
